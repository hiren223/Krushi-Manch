Herbicide Information

Glyphosate

Common Name: Glyphosate

Type: Broad-spectrum systemic herbicide

Application: Pre- and post-emergence application to control weeds

Target Weeds: Annual and perennial weeds, grasses

Mode of Action: Inhibits amino acid production in plants

Atrazine

Common Name: Atrazine

Type: Selective herbicide

Application: Pre-emergence application for weed control

Target Weeds: Broadleaf weeds, grasses

Mode of Action: Inhibits photosynthesis in weeds

2,4-D

Common Name: 2,4-Dichlorophenoxyacetic acid

Type: Selective herbicide

Application: Post-emergence application for broadleaf weed control

Target Weeds: Broadleaf weeds

Mode of Action: Synthetic auxin affecting cell growth

Roundup

Common Name: Glyphosate

Type: Non-selective herbicide

Application: Post-emergence application for a broad spectrum of weeds

Target Weeds: Grasses, broadleaf weeds, and woody plants

Mode of Action: Inhibits amino acid synthesis in plants

Dicamba

Common Name: Dicamba

Type: Selective herbicide

Application: Post-emergence application for control of broadleaf weeds

Target Weeds: Broadleaf weeds

Mode of Action: Affects plant growth by disrupting cellular processes

Paraquat

Common Name: Paraquat

Type: Non-selective herbicide

Application: Post-emergence application for rapid weed control

Target Weeds: Broad-spectrum control

Mode of Action: Inhibits photosynthesis by disrupting electron transport

Pendimethalin

Common Name: Pendimethalin

Type: Pre-emergence herbicide

Application: For weed control in crops like corn and soybean

Target Weeds: Grass and broadleaf weeds

Mode of Action: Inhibits cell division in plants

Flumioxazin

Common Name: Flumioxazin

Type: Pre-emergence herbicide

Application: For broad-spectrum weed control

Target Weeds: Broadleaf weeds and grasses

Mode of Action: Inhibits chlorophyll synthesis in plants

S-metolachlor

Common Name: S-metolachlor

Type: Pre-emergence herbicide

Application: For weed control in crops like corn and soybeans

Target Weeds: Grasses and broadleaf weeds

Mode of Action: Inhibits growth in seedlings by blocking cell division

Metolachlor

Common Name: Metolachlor

Type: Pre-emergence herbicide

Application: Effective for weed control in various crops

Target Weeds: Annual grasses and broadleaf weeds

Mode of Action: Inhibits the germination of seeds

Isoxaflutole

Common Name: Isoxaflutole

Type: Pre-emergence herbicide

Application: For broad-spectrum weed control in corn

Target Weeds: Grasses and broadleaf weeds

Mode of Action: Inhibits the production of key enzymes involved in plant growth

Mesotrione

Common Name: Mesotrione

Type: Post-emergence herbicide

Application: Effective for weed control in corn

Target Weeds: Broadleaf weeds

Mode of Action: Inhibits the production of carotenoids in plants
